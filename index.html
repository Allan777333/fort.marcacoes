        Onde seus dados ficam salvos

        Todos os agendamentos ficam salvos diretamente no seu aparelho, usando a memória local do navegador ( localStorage). Isso significa que:

        • Se você fechar o app e abrir de novo, seus dados continuam lá normalmente.
        • Os dados são preservados mesmo se você desligar o celular ou computador.
        • Se você abrir em outro celular ou navegador, os agendamentos não aparecerão, porque cada aparelho salva os dados separadamente.
        • Se limpar os dados ou cache do navegador, ou desinstalar o app, os agendamentos serão apagados.

        Para manter uma cópia de segurança, utilize o botão Baixar PDF na página Lista.

        Instalar este app (sem loja)

        Você pode instalar este app no seu celular ou computador como atalho de tela cheia (PWA). Toque no botão 📲 Baixar App no topo. O botão fica ativo quando o navegador permitir a instalação. Também é possível usar a opção “Adicionar à tela inicial” do navegador.
